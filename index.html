Prototyping and Implementation

Technical architecture and feature development process

System Architecture

Climblink adopts a three-tier architecture: frontend built with Vue.js 3 for responsive user interfaces, Firebase as the backend-as-a-service handling authentication, real-time database, and cloud storage, and LBS integration via Google Maps API for location-based services.

AI-Powered Matching Engine

The intelligent matching algorithm analyzes user profiles considering skill level, availability, preferred gyms, and climbing preferences. Machine learning models continuously improve match quality based on user feedback and interaction patterns.

Core Technical Stack

Vue 3 with Composition API • Firebase Authentication & Firestore • Google Maps LBS API • TensorFlow Lite for on-device ML • Responsive Design with CSS3 Flexbox/Grid

User Authentication

Secure OAuth 2.0 login with phone verification, profile management, and session persistence.

Location Services

Real-time gym discovery, distance calculation, and location-based recommendations.

Social Features

Real-time messaging, community forums, event creation, and achievement sharing.

Evaluation and Results

Quantitative and qualitative assessment of system performance

Usability Testing Results

Task Completion Rate
  • Find climbing partner: 96%
  • Discover nearby gym: 94.5%
  • Create climbing event: 93.25%
  • Join community forum: 91.25%
SUS Scores
Beginner users: 71.63 (Acceptable)
Intermediate users: 78.25 (Good)
Advanced users: 83.0 (Excellent)
Task Time Analysis
Average task completion time reduced by 42% compared to traditional methods (WeChat groups).

Matching Algorithm Experiment

Experimental Design
  • Participants: 40 climbers (20 beginners, 20 intermediates)
  • Conditions: AI-based matching vs. Random matching
  • Duration: 4-week trial period
Key Findings
  • AI matching achieved 78% partner satisfaction rate
  • Random matching achieved 45% partner satisfaction rate
  • AI group had 3.2 more climbing sessions on average
  • Skill progression rate increased by 28%
Statistical Significance
Independent t-test: p < 0.01, Cohen's d = 0.87 (large effect size)

Discussion and Reflection

Analysis of findings, challenges, and lessons learned

Key Insights

User testing revealed that introverted users particularly valued the AI matching feature, as it reduced social anxiety associated with approaching strangers. The gamification elements (badges, achievements) significantly increased user engagement and retention rates.

Challenges Encountered

Location accuracy in indoor environments proved challenging. Initial cold-start problem for new users without climbing history required careful onboarding design. Maintaining engagement during off-peak hours remains an ongoing challenge.

Iterative Improvements

Based on feedback, we implemented: 1) Enhanced onboarding tutorial for beginners, 2) Improved gym recommendation algorithm, 3) Real-time availability indicators for partners, 4) Community moderation tools to maintain quality interactions.

User Pain Points Addressed

87% of users reported reduced loneliness in climbing activities

Time Efficiency

Partner matching time reduced from hours to minutes

Skill Improvement

Users reported faster skill progression with matched partners
