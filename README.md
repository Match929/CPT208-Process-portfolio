# C2-2-Rock climbing app-Process-portfolio
This is a process portfolio website for the CPT208 Human-Centric Computing course. It records the whole process of our project "Rock climbing and social media app": research → design → development → testing.

## 🚀 Project Introduction
A modern, responsive static website built for our rock climbing & social media application project.  
Deployed on GitHub Pages for team presentation and course submission.


## 🛠️ Tech Stack
- **React 18** - UI framework
- **Vite** - Build tool
- **React Router DOM** - Routing
- **Three.js** - 3D effects (ColorBends)
- **GSAP** - Animation library
- **OGL** - WebGL library
- **Canvas** - Custom particle effects

## 📦 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/match929/CPT208-Process-portfolio.git

# 2. Navigate to project directory
cd CPT208-Process-portfolio

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```
